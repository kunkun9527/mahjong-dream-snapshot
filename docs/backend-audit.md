## 三麻半庄意外返回大厅排查

用户提供两次“页面断开 → AI 接管 → 结算 → 页面重连”的控制台记录。旧服务仅打印断开提示，没有持久化日志、关闭码或原因，不能追溯认定这两次的真实断线来源。

已独立复现 `mock/server.js` 的旧防刷逻辑：2 秒内 10 次 `100141` 资料查询即 `close(1001, 'spam reset')`，导致正常短时突发查询也被踢下线。现已删除强制断线，保留权威版本同步；20 次连续查询的处理器回归和真实回环 WebSocket 集成测试均通过。该缺陷与用户现象相符，但仍需用户重启后复测，不能声称已证明唯一根因。

`local/server.mjs` 现在每次断线在控制台记录时间、关闭码、原因、是否服务端主动关闭、连接时长、最近 12 个请求编号和是否局中；不记录手牌、存档或完整报文，也不另建持久化日志。再次发生时请保留 `WebSocket 关闭：` 那一整行及浏览器 Console 错误。

### 后续：通知与心跳下行序号倒序

去除防刷后仍收到客户端 `1000 / Bye!`、`serverClose: null`，不能继续归因于 `spam reset`。已有隔离日志中，心跳仍有回复，断线前同一连接按 **36 → 38（心跳）→ 37（摸牌通知）→ 39** 收到外层 f27；客户端画面同时滞后。`Bye!` 是通用关闭理由，仅凭它不能认定唯一关闭调用点。

源码确认 `Session.push()` 在异步投递前调用 `wrap()` 分配 f27，而 `dispatch()` 返回的心跳响应由 `local/server.mjs` 立即发送，存在确定的序号倒退。修复为异步回调真正发送前才打包，并校验 socket 仍属于本会话；保留通知间 FIFO、通知不带 f11、动作响应回显原 RPC 序号和虚拟连接异步边界。

- `test/transport-order.test.mjs`：3 项回归在旧实现下失败，修复后通过；覆盖心跳超车、连续通知/响应、连接替换。
- `test/claim-timing.test.mjs`：5 项假时钟回归确认现有鸣牌窗口在备用时间为 0 时仍有完整基础 5 秒、备用时间为 20 时等待 25 秒、最后一毫秒可碰、按实际使用扣备用时间且无残留超时。本轮没有凭显示异常擅自延长规则时限。
- 修复后执行 `npm run build`、`npm run check`、`npm test`（**97/97**，无跳过）；浏览器 bundle 重建无内容变化。

验证边界：按用户要求停止浏览器复现，补丁后仅执行源码检查和自动化测试。序号缺陷已确认并修复，但尚未证明它是所有 `Bye!` 断线或鸣牌倒计时显示异常的唯一原因；也没有改动断线立即 AI 接管的既有策略。

## 鸣牌按钮出现后立即跳过：会话设置与等待链路

后续源码检查确认了另一条确定的提前过牌路径：`local/server.mjs` 从档案载入历史 `internalState`，经 `Session`、`RiichiSession` 原样启用；其中 `2=true` 表示“不鸣”，会让 `waitHuman('claim')` 立即提交 `Guo`。但 `NtfGameStart` 不包含这些开关，界面不一定恢复同一状态，于是仍显示吃/碰/杠按钮，后端却不等待。只读检查原 Unity 的鸣牌入口也确认 `2=true` 会抑制按钮，不能通过反转这个布尔值修复。此前直接测试默认引擎计时遗漏了这条历史设置载入链路。

修复：

- `mockjs/browser_entry.mjs` 分离历史缓存与当前客户端提交的设置；只有后者可以激活自动操作，准备前提交也能在惰性创建引擎后生效。保留存档内容和格式，不直接修改运行时档案。
- `mock/server.js` 更换连接时使旧自动操作授权失效，同一连接不重复清除；不重置本小局备用时间。客户端明确开启“不鸣”仍可自动过，关闭后正常等待。
- `mockjs/engine.mjs` 非托管窗口先建立原截止时间，自动动作微任务执行时再次检查设置；取消不鸣后不能继续执行已排队的旧过牌，也不能因此重新获得 25 秒。

`test/claim-session-regression.test.mjs` 新增 **19 项**，走真实会话设置、protobuf 动作请求、弃牌通知及鸣牌执行链路，而不只是直接调用计时器：覆盖三麻碰/明杠、四麻吃/碰/明杠在 24 秒后仍可选择，备用耗尽后仍有完整 5 秒，出牌与鸣牌共用备用时间、下一小局补满，三麻拒吃、四麻仅能吃上家，以及明确不鸣、取消、局部设置和连接替换。首批 9 项修复前 7 项失败；另一个取消不鸣微任务回归也先失败后通过。

最终执行 `npm run build`、`npm run check`、`npm test`：**128/128 通过**，无跳过，浏览器 bundle 已重建。没有启动浏览器，尚未完成人工确认倒计时显示和按钮交互；也没有宣称此补丁解决全部断线问题。
